ROBOT TITAN - Forge 1.20.1

BUILD: upload this whole folder's contents to a new GitHub repo; the included
.github/workflows/build.yml compiles it. Download the jar from Actions > latest run > Artifacts.

PLAY
- Titan Core is in the creative Combat tab.
  Survival recipe: 4 iron blocks + 4 redstone blocks + nether star (ring, star in the middle).
- Right-click a block with the Titan Core: your titan lands there.
- Right-click the titan (empty hand or any item): you climb into the hatch on top.
- W/A/S/D walk, mouse aims, it steps up 3-block walls. Shift to climb out.
- Hold the Titan Core and right-click while piloting: fire the cannon.
- Hostile mobs next to a piloted titan get stomped.
- If the titan is destroyed it drops the core.
